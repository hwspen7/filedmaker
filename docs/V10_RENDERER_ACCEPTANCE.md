# Seat Studio v10 — geometry and publication acceptance

The previous viewer rendered oversized chair backs, floating treads and undifferentiated synthetic venue geometry. v10 replaces the default 3D renderer with a native WebGL2 instanced geometry engine. The school editor, public viewer and offline school export now use the same geometry planning and viewer code.

## Source and ticket constraints

- **Published capacity** comes from dated official venue information where available.
- **Imported ticket identities** come only from an authorized school-provided inventory.
- **Visual positions** can be generated from geometry parameters and must be labeled synthetic until validated.
- No fake real-time inventory, hold status, ticketing integration or official seat IDs are generated by capacity matching.

## Geometry rules

- Each chair is an approximately half-metre-wide compact seat with a thin back, low arms and narrow supports. A single chair back must never fill an entire human-eye camera view.
- Football tiers default to backless bleacher-like seating unless the input includes a specific seat style.
- Every generated row receives a visible tread and riser, with section gaps kept open. Cross-section geometry is deliberately minimal, not a surveyed building.
- Human eye height uses distinct seat and eye anchors. The native renderer excludes very-near furniture during the preview instead of claiming measured obstacles.
- Camera FOV, orbit, first-person look direction and relative vertical row changes are defined in metres and radians.
- Colors are determined by the source venue or school brand and can be overridden without changing seat data.

## Local graphic-device acceptance (mandatory before deployment)

1. Open `/` on a Windows Chrome or Edge machine with WebGL2 enabled.
2. Select **Schottenstein Center** and compare whole-arena seat layout, tier breaks and court proportions against a real photo. Verify that chairs appear compact and oriented towards the court.
3. Select **Human eye** after choosing a seat. Check that the own seat or adjacent furniture does not occupy the viewport. Record a screenshot.
4. Select **Ohio Stadium** and verify the seating type is backless rather than millions of fabricated folding chairs. Confirm the capacity panel displays official capacity separately from visual position count.
5. Import an authorized seat roster and inspect exact seat IDs and row order in both `/school/` and `/viewer/`.
6. Export an offline school preview and open it without a network connection. Verify 2D map and 3D view load.
7. Do not approve a particular school model as accurate until real photos and a seating chart confirm multiple measured row and section locations.

### Known constraints

- The OSU stadium and Schottenstein examples are approximate geometry and do not contain authorized surveyed per-seat positions.
- Native WebGL2 is required for 3D. The 2D preview remains available without it.
- A whole-bowl rendered model does not prove official ticket availability.
- The legacy editor remains at `/legacy/` for advanced editing and GLB export. Its old CDN-based 3D pipeline has not been independently visual-validated in v10.
- CI currently exercises deterministic geometry, source integrity, offline HTML parsing and server routes. GPU pixel comparison must be run on an actual WebGL2 device.
